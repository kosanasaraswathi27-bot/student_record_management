New student record

Before you add

  • Registration numbers use 3 to 15 letters, digits or hyphens, and each one must be unique.
  • Names can include letters, spaces, dots, hyphens and apostrophes.
  • Marks are a number from 0 to 100 with up to two decimal places.
  • A new record is linked in after the last node of the list.

Find a student

How the search works

  • It starts at the head and compares each node's registration number with yours.
  • It stops at the first match, or at NULL if there is none.
  • Upper and lower case are treated the same.

Delete a student

Before you delete

  • You will be asked to confirm before anything is removed.
  • The matching node is unlinked, and the node before it now points to the node after it.
  • A deleted record cannot be restored. Use Reset demo data in the sidebar to bring back the samples.
